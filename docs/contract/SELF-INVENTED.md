# SELF-INVENTED — 自创机制登记

> 判定标准：MoS（Go）与 PI/DSH 都没有等价物，而 Java 侧必须做。登记 = 让评审者重点看；自创机制**不许放宽任何 fail-closed 分支**（INVARIANTS I1）。

| 编号 | 机制 | 为什么 Java 不能照做 | Java 侧做法与代价 | 状态 |
|---|---|---|---|---|
| SI-1 | `CancellationToken`（取消传播） | Go 用 `context.Context` 的结构化取消；Java 无等价强制力 | 自有令牌类型贯穿所有可阻塞点；代价：每个阻塞点必须显式响应（清单随 mos4j-core 维护），漏检靠 T6.4 清单逐项测试拦截 | **已落地（J1+J6+加固批次）**：HTTP 层真中止（`sendAsync` + `Future.cancel`，J1）+ ExecPath 取消贯通（取消不留空洞，J6）+ 重试退避分片检查（J6）+ **agent→driver→planner→model→ExecPath 全链贯通**（加固批次：`Agent.run` / `LoopDriver.run` / `Planner.nextAction` 的 token 重载 + `ReActPlanner` 直传模型 + 取消优先于完成 + 取消先于落盘）；`LoopDriver` / `Planner` 的扩展点默认重载**只做调用前检查**并声明「不响应中途取消」 |
